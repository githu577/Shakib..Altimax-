## ◈ About

Assalamu Alaikum! **GoatBot-Shakib** is a customized fork of
[Goat Bot V2](https://github.com/ntkhang03/Goat-Bot-V2) by
**NTKhang**, modified and maintained by **Shakib** with custom
features, commands, improvements, and additional functionality.

| Feature | Description |
|---|---|
| 🔌 **Custom FCA** | Uses the configured FCA package for Facebook Messenger communication |
| ⚙️ **Handler Improvements** | Improved command handling and bot administration |
| 🌐 **Multi-Language** | Supports multiple languages depending on configuration |
| 🎨 **UI Improvements** | Clean message templates and formatted responses |
| 🛡️ **React Unsend** | Optional automatic message unsend through reactions |
| 🔧 **Setting Command** | Configure bot settings directly from Messenger |

> ⚠️ For educational purposes only. Any misuse or illegal activity is solely the user's responsibility.
